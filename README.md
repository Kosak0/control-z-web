## 💡 Sobre el proyecto

**Control Z** es la cafetería del Campus Córdoba. Este proyecto simula el desarrollo de su página web siguiendo la metodología **Scrum**, como ejercicio académico.

La web permitirá a la comunidad universitaria:

- 📖 Consultar la carta con precios y categorías
- 🥗 Filtrar los productos por alérgenos y dietas
- 🪑 Reservar mesa
- 🕒 Ver el horario y la ubicación de la cafetería
